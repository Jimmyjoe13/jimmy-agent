Code signing policy

Statut : la signature gratuite de l'installeur Windows est en cours de demande auprès de SignPath Foundation. Tant qu'elle n'est pas accordée, l'installeur n'est pas signé et Windows affiche un avertissement.

Status: free code signing for the Windows installer has been requested from SignPath Foundation. Until it is granted, the installer is unsigned.

Once granted: Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Ce qui est signé / What gets signed

  • Uniquement l'installeur Windows de Jimy (Jimy-setup.exe) et l'application qu'il installe, construits par GitHub Actions à partir du code public du dépôt github.com/Jimmyjoe13/jimmy-agent (workflow installeur-windows.yml).
  • Only the Jimy Windows installer and the application it installs, built by GitHub Actions from the public source code of the repository above. No binary built on a personal machine is signed.
  • Chaque demande de signature est approuvée manuellement / Every signing request is approved manually.

Équipe / Team roles

  • Committers and reviewers: Jimmyjoe13
  • Approvers: Jimmyjoe13

Les membres de l'équipe utilisent l'authentification à deux facteurs sur GitHub et SignPath. / Team members use multi-factor authentication for GitHub and SignPath.

Confidentialité / Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. Détail : politique de confidentialité.
