Comment ça marche

Pas un chatbot dans une fenêtre. Un coloc.

Jimy reste sur ton bureau, au-dessus de tes fenêtres. Tu peux le déplacer, il esquive ta souris, et il réagit à tout ce qu'il fait.

  1. 01

    Tu l'appelles

    « Jimy… » — il répond « Oui ? ». Le mot d'éveil est détecté sur ta machine : l'audio de ton micro n'en sort pas.

  2. 02

    Il réfléchit

    Avec le modèle de langage que tu choisis, et ta propre clé : OpenCode Go, OpenRouter, Claude ou ton fournisseur.

  3. 03

    Il agit

    Fichiers, commandes, navigateur, serveurs MCP. Tout ce qui engage — payer, envoyer, supprimer — attend ton feu vert.

  4. 04

    Il répond

    À voix haute, avec une bulle et une animation. Et il retient ce qui compte pour la prochaine fois.

Vie privée

Il vit chez toi. Pas chez nous.

Jimy tourne sur ta machine. Seuls partent sur le réseau les échanges nécessaires : ton fournisseur de modèle, la synthèse vocale, et ce que tu lui demandes de faire en ligne. Tout le détail.

  • Pas de compte, pas de pub, pas de télémétrieRien n'est envoyé à l'auteur de Jimy.
  • Ton micro ne sort pas de ton PCLa reconnaissance vocale (whisper.cpp) tourne en local, hors ligne.
  • Tes clés restent sur ta machineHistorique, mémoire, réglages et clés d'API sont stockés localement.
  • Code ouvertLicence MIT sur GitHub ; l'installeur est construit par GitHub Actions à partir de ce code.

Installer

Trois minutes, et il est là.

  1. Lance l'installeur

    Jimy-setup.exe. Windows peut afficher « Windows a protégé votre ordinateur » (installeur pas encore signé) : Informations complémentaires, puis Exécuter quand même.

  2. Laisse-le s'équiper

    Au premier lancement, il télécharge sa reconnaissance vocale (environ 65 Mo, puis 180 Mo en option). L'écoute s'active à la fin.

  3. Donne-lui un cerveau

    L'accueil te demande une clé de modèle de langage (OpenCode Go ou OpenRouter). Elle reste sur ta machine.

Windows bloque l'installeur ? C'est normal, pour l'instant.

Jimy n'a pas encore de certificat de signature (demande en cours auprès de SignPath Foundation). Sans lui, Microsoft Defender se méfie de tout nouveau programme. L'installeur est construit par GitHub Actions à partir du code public : télécharge-le uniquement depuis ce site ou depuis les Releases GitHub.

1. Au téléchargement (Edge)

« Jimy-setup.exe n'est pas fréquemment téléchargé » : survole le fichier dans les téléchargements, clique sur … → Conserver, puis Afficher plus → Conserver quand même.

2. Au lancement (SmartScreen)

« Windows a protégé votre ordinateur » : clique sur Informations complémentaires, vérifie que le fichier s'appelle bien Jimy-setup.exe, puis Exécuter quand même.

3. Si le fichier disparaît

Defender l'a mis en quarantaine. Ouvre Sécurité Windows → Protection contre les virus et menaces → Historique de protection, choisis l'élément Jimy, puis Actions → Autoriser sur l'appareil. Relance l'installeur.

Sous Windows 11, si c'est le Contrôle intelligent des applications qui bloque, il n'y a pas de bouton « Exécuter quand même » : attends la version signée plutôt que de désactiver cette protection. Ne désactive jamais l'antivirus pour installer Jimy.

FAQ

Les questions qu'on nous pose.

C'est vraiment gratuit ?

L'appli et les cinq skins de base, oui, et le code est open source. Il te faut une clé chez un fournisseur de modèle de langage (OpenCode Go, OpenRouter…) : c'est lui qui facture l'usage, selon le modèle choisi. Les skins premium seront payants.

Il m'écoute en permanence ?

Le micro est ouvert pour entendre « Jimy », mais tout se passe sur ta machine : l'audio ne part jamais sur Internet. Après une réponse, il garde l'oreille ouverte quelques secondes pour enchaîner sans redire son nom. Tout se règle ou se coupe dans Paramètres → Écoute.

Quelle machine faut-il ?

Windows 10 ou 11, 64 bits. Jimy est développé sur un portable Ryzen 7 avec 16 Go de RAM, sans carte graphique dédiée. L'avatar a trois profils graphiques pour les machines plus modestes.

Pourquoi Windows affiche un avertissement ?

L'installeur n'est pas encore signé. Une signature gratuite est demandée à SignPath Foundation (Code signing policy). En attendant, l'installeur est construit par GitHub Actions à partir du code public, que tu peux vérifier. Pas à pas pour l'autoriser : voir ici.

Et sur Mac ?

C'est la prochaine étape. Pour l'instant, Jimy n'existe que sur Windows.

Comment j'active un skin premium ?

La boutique n'est pas encore ouverte. À l'ouverture, tu recevras une clé de licence après l'achat : dans l'appli, onglet Skin → « Skins premium », colle-la et clique sur Activer. Le skin se télécharge tout seul.
