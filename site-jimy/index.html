Télécharger Jimy pour Windows

Ton agent personnel, sur ton bureau : avatar 3D, voix en local, et il agit pour toi. Version bêta, gratuite et open source.

⬇ Télécharger l'installeur (Windows 10/11)
  1. Lance Jimy-setup.exe. Windows peut afficher « Windows a protégé votre ordinateur » (application pas encore signée) : clique sur Informations complémentaires puis Exécuter quand même.
  2. Au premier lancement, Jimy télécharge sa reconnaissance vocale (environ 65 Mo, puis 180 Mo en option) : l'écoute s'active à la fin.
  3. Il te faut une clé de modèle de langage (OpenCode Go ou OpenRouter) : l'écran d'accueil te la demande, elle reste sur ta machine.

Code source et notes de version : github.com/Jimmyjoe13/jimmy-agent. Installeur construit par GitHub Actions ; signature gratuite demandée à SignPath Foundation (Code signing policy). Confidentialité. Mac : bientôt.
